# Задание 4

Дашборд «CityBikes: обзор сетей» показывает данные таблицы
citybikes.anton_mishin_dm из ClickHouse. Настройки сохранены в metabase.dump,
резервной копии служебной базы Metabase. Она восстанавливается автоматически
при первом запуске Docker через restore_metabase.sh.

Для загрузки данных выполнить задания 1-3 или общий DAG и дождаться success.

Открыть http://localhost:3000/dashboard/2.

Логин: anton.mishin@example.com

Пароль: Citybikes2026!

Дашборд также доступен в коллекции CityBikes.

Вверху показаны доступные велосипеды, свободные места и число станций
с велосипедами и без них. Ниже - сравнение сетей, электровелосипеды,
способы оплаты, статус аренды, полнота данных и список станций.
Фильтр «Сеть» действует на весь дашборд и допускает несколько значений.
Остальные фильтры относятся только к списку станций; поиск по названию
работает без учёта регистра. Страницы таблицы можно перелистывать.
Лимит ответа Metabase - 10 000 строк, текущие 4 153 станции помещаются целиком.

Доли нулевых остатков считаются среди станций с известным значением.
Пропуски не считаются нулями. Способы оплаты могут пересекаться,
пустой список обозначен «Не указано». Включённая аренда или возврат
не гарантируют наличие велосипеда или места.
Неполный статус - нет сведений об аренде или возврате.
График оплаты показывает карту и телефон; полный список есть в таблице станций.

По снимку от 10.10.2026 у Divvy 42,4% станций без велосипедов,
у Vélib - 6,7%. Метки API у Nubija относятся к декабрю 2025 года,
у Abu Dhabi - к августу 2026 года. Их остатки нельзя считать текущими.
У Nubija и Bicielx отсутствуют
статус аренды и дата отчёта. Такие пропуски не обязательно являются ошибками.
По одному снимку нельзя определить популярность станций и количество поездок.
Свободные места не показывают число велосипедов в аренде
Часовой пояс даты отчёта принят условно, как описано в задании 3.

Запросы и настройки дашборда хранятся в служебной базе metabase
в PostgreSQL. Подключение использует встроенный драйвер ClickHouse.
Копия также содержит учебного пользователя и подключение к ClickHouse
внутри Docker.

Повторный запуск сохраняет готовый дашборд и правки из интерфейса.
Редактировать вопросы, графики и фильтры можно прямо в Metabase.
Чтобы передать внесённые правки вместе с проектом, обновить копию базы
из корня проекта:

```powershell
docker compose exec postgres pg_dump -U airflow -d metabase --format=custom --no-owner --no-acl --file=/tmp/metabase.dump
docker compose cp postgres:/tmp/metabase.dump Task4/metabase.dump
```

Файл предназначен для PostgreSQL 16 и указанной в Docker Compose версии
Metabase. Существующая база при запуске не заменяется новой копией файла.
Окружение описано в [главном README](../README.md).
